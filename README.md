AI Mock Interview Platform
PrepWise is an AI-powered mock interview platform designed to help users prepare for interviews with confidence. The platform creates realistic interview experiences, provides smart feedback, and helps users improve their communication and problem-solving skills using AI.
Features
Conduct AI-based mock interviews
Get instant feedback on responses
Practice technical, HR, and behavioral questions
Improve confidence through real interview simulations
User authentication and personalized experience
Clean and responsive user interface
Tech Stack
React 19
Vite
Tailwind CSS
Firebase
Google Gemini API
Clerk Authentication
Getting Started
1. Clone the Repository
Bash
git clone <repository-url>
2. Install Dependencies
Bash
npm install
3. Run the Development Server
Bash
npm run dev
4. Create Production Build
Bash
npm run build
Available Scripts
Bash
npm run dev      # Start local development server
npm run build    # Generate production build
npm run lint     # Check code quality using ESLint
npm run preview  # Preview production build locally
